Installed — pairing is still required

The LaunchDaemon has started, but it will not send authorized telemetry until it is paired.

Create a one-time activation key in xsos, then run in Terminal:

sudo -u _xsoc /usr/local/bin/xsoc pair --config '/Library/Application Support/xsoc/config.json' --server https://xsos.example.com --output human

Replace the example URL with your console origin. To inspect the service later, use sudo launchctl print system/org.sarmg.xsoc.
