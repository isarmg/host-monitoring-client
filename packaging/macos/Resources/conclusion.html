Installed — pairing is still required

The LaunchDaemon has started, but it will not send authorized telemetry until it is paired.

Create a one-time activation key in Host Monitoring, then run in Terminal:

sudo -u _hostmonitor /usr/local/bin/host-monitor pair --config '/Library/Application Support/host-monitor/config.json' --server https://host-monitoring.example.com --output human

Replace the example URL with your console origin. To inspect the service later, use sudo launchctl print system/org.sarmg.hostmonitor.
