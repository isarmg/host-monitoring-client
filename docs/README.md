# xsoc 使用文档

xsoc 是只读主机监控客户端，以系统服务主动连接 xsos。这里从安装一台主机开始，介绍当前 1.0.0 的使用和维护。

## 第一次使用

1. [安装并配对](platform-setup.md)：按 Windows、Linux 或 macOS 完成一个完整流程。
2. [确认运行](usage.md)：查看服务、绑定及最新报告。
3. [调整配置](configuration.md)：修改设置或准备自动化输入。
