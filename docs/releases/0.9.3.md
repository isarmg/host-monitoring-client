# Host Monitoring Client 0.9.3

独立只读遥测 Client 的首次安装包发行，不包含 Server 或管理 Web。

- Linux x86_64：DEB、RPM，构建基线 Ubuntu 24.04 / glibc 2.39，依赖 systemd。
- Windows x86_64：MSI，包含服务、托盘与维护程序，未进行 Authenticode 签名。
- macOS Apple Silicon：原生 PKG，未使用 Developer ID 签名或公证，不能视为已通过 Gatekeeper 的正式签名发行。
- Android/iOS 仅提供宿主驱动的 Rust 库源码与编译检查，不存在独立移动应用，不提供虚构 APK/IPA。

安装包与各平台 manifest 记录源码提交和 SHA-256；源码依赖固定 Foundation Client 和产品 Server 协议提交。客户端使用 HTTPS 与独立设备配对凭据，不提供任意远程执行。

此发布标记为预发布，便于对拆分后安装包进行环境验收。CI 覆盖三平台原生 Rust 测试、打包生命周期测试、Windows PE/WiX 校验、Linux TLS 和 OTLP 闭环；这不等于所有目标机器的真实安装、签名或升级验收。不提供旧状态兼容、迁移或自动升级。
