# host-monitoring-client 0.9.36

- 常驻采集的首份报告使用配置的下一次采样周期声明上报节奏，供 Server 判断主机在线状态；网络和磁盘速率仍以实际采样时长计算。
- 物理网卡清单的接口关联与条目数量经过边界校验，采集数据保持在报告协议允许范围内。
- 本版本继续使用报告 schema 3；配套 Server 0.9.31 提供按服务器接收日期查看完整上报日志的 Web 页面。配置与身份格式仍为 0.9.4。
- 通用 CLI、受保护文件读取与运行时依赖固定到 Foundation Client 0.9.16。
- 本机状态的 checks.report_auth 保留上报凭据检查结果，status 与 doctor 均只显示诊断状态，不显示凭据内容。

## 验证

完整 Rust、严格 Clippy、原生安装和移动库门禁由发行 tag 的 GitHub Actions 执行；正式资产与校验和以该 CI 的 GitHub Release 为准。
