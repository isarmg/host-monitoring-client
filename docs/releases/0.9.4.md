# Host Monitoring Client 0.9.4

修复 Windows 全新 MSI 安装时报 Error 1920、host-monitor 服务退出的问题。

根因：安装器使用 ClientConfig::default() 写入 HTTP 回环端点，而正式构建的
Foundation 网络策略仅允许 HTTPS。服务读取默认配置即失败，尚未进入等待配对状态。
默认端点现为 HTTPS；未配对时仍不发送遥测，不降低证书或网络策略要求。

增加与 release 构建策略一致的默认配置往返校验测试，并把实际 MSI 安装、启动、
修复、回滚和卸载测试接入 Windows CI。具有删除测试状态等副作用的完整生命周期
脚本只能在一次性的 GitHub 托管 runner 上执行，禁止用于用户主机。

本版本是新的客户端安装包；不覆盖 0.9.3 历史发行，不转换旧配置或旧身份。
服务端协议依赖保持不变，仍明确支持 Server 0.9.3；健康检查不再错误地把客户端
补丁版本当成 Server 版本要求。Windows 安装包仍未进行 Authenticode 签名。
