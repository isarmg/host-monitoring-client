# Host Monitoring Client 0.9.10

统一安装契约：Windows x64、Linux x86_64 和 macOS Apple Silicon 各自只发布一个原生安装包，不再把 PowerShell 或 Shell 安装脚本作为发行资产。

新增 `host-monitor setup`。有交互终端的原生安装器在注册低权限服务后会直接启动设置向导，依次完成 Server/授权码配对，询问是否启用开机运行、立即启动并验证连接；静默或无终端安装会保留进度。配对失败保留安装、身份和安全进度，可再次运行 `setup` 或恢复原配对事务。受保护 stdin 的非交互模式默认完成同一服务生命周期。

`setup` 对已完成身份幂等，对未完成事务自动恢复；守护进程仍不从 `run`、开机启动或服务启动路径隐式配对，也不生成第二个守护进程。既有 `pair`、`status`、`doctor`、`config`、`service` 和 `logs` 命令继续保留为显式运维入口。

安装包仍保留配置、身份、队列、日志和服务启动意图；升级、修复、降级检测由原生安装器处理。安装产物未签名、未公证，真实 Server 配对仍需目标环境验收。
