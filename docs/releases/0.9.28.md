# host-monitor 0.9.28

- Windows MSI 使用明确的自定义安装页，允许选择程序安装目录，并分别选择是否保留旧 `config.json` 与旧身份、凭据和采集队列；两类状态默认保留。
- 原生维护程序不再假定 `%ProgramFiles%\host-monitor`，而是校验 MSI 解析后的目标可执行文件路径，因此自定义目录仍使用同一套服务、ACL 与防重解析点保护。
- 取消保留配置或数据时，只在 MSI 最终提交阶段执行相应清理；异常路径或文件类型会使安装明确失败，而不是静默跳过。
- 图形安装显示完成或失败页；PowerShell 安装入口默认显示完整 MSI UI，`-Quiet` 仅用于明确的自动化流程，并在结束后输出成功或错误及日志位置。
- Windows MSI 默认提供“Prepare incompatible account data for Setup”选项：只在 Host UUID 与 spool 验证通过后归档不兼容账户文件；普通 `setup` 会自动恢复仅有本地身份或已保留 Host UUID 的状态。
