# Host Monitoring Client 0.9.23

- 修复 Apple Silicon macOS 安装包未声明 `hostArchitectures="arm64"`，从而可能在 M2 等设备上错误提示安装 Rosetta 的问题。
- macOS 打包前严格验证主程序是纯 ARM64 Mach-O，最终 PKG 安装烟测同时检查 Distribution 声明和全部 Mach-O 载荷。
- CI 显式构建 `aarch64-apple-darwin` 目标，并从该目标目录验证源码身份和生成安装包，避免宿主默认目标掩盖架构错误。
- 仍只发布 Windows x64、Linux x64 和 macOS Apple Silicon 当前版本安装包，不增加 Intel macOS 或旧安装协议兼容。
