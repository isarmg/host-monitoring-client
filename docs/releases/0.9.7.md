# Host Monitoring Client 0.9.7

修复 Windows MSI 在旧服务登记残留、程序和状态目录已经丢失时于 PrepareClientInstall 步骤报 1722/1603 的问题。安装器验证原服务的固定路径和 LocalService 身份后修复安装，并默认记录受保护的详细失败原因。

新增 Windows 安装修复脚本，处理早期 MSI 产品登记、重试安装器忙碌、强制覆盖损坏或同版本程序文件；后续 MSI 使用稳定升级标识。Linux 与 macOS 接受兼容旧版的账户所有权记录，覆盖安装无需清除凭据和队列。

新增 [各平台安装配置指南](../platform-setup.md)，包含 Windows 管理员终端、DEB/RPM、Apple Silicon PKG、配对、服务操作、配置路径和日志。配置及持久身份格式仍为 0.9.4，程序版本为 0.9.7。

CI 回归覆盖残留服务、旧标记保留、损坏程序强制替换，以及原有 ACL、回滚与卸载行为。发行安装包未签名、未公证；macOS 仅支持 Apple Silicon。
