# Host Monitoring Client 0.9.27

`0.9.27` 修复 macOS PKG 覆盖安装被旧 receipt 或 ownership marker 错误阻断的问题。

## 修复

- `preinstall` 不再把 PKG 软件版本误判为 Client 持久状态格式，也不再维护历史发行版白名单。
- ownership marker 使用独立的 `marker_format=1` schema，并分别记录 `last_package_version` 与固定的 `state_format=0.9.4`。
- 安装成功时会以原子 rename 覆盖旧的 `format=<package-version>` marker；旧字段只作为账户所有权证明读取，不再参与状态兼容性判断。
- `uninstall.sh --purge` 能读取新 marker，并在部分清理后继续以新 schema 原子更新所有权证明。
- Linux 账户所有权 marker 同样不再用逐版本白名单冒充状态格式；`0.9.x` 来源版本经严格数字校验后按账户 ID 绑定处理。
- 0.9.3 配置、配对、绑定和授权文档与固定 0.9.4 schema 结构相同，现在会透明读取，并在后续正常提交时继续写固定的 0.9.4 格式。
- 真正未知或损坏的账户文档返回 `pairing_state_incompatible`。`pair recover --interactive` 会先确认 spool 可读，再归档配对、授权、绑定和凭据文件；Host UUID 与采集队列不在归档列表中。
- spool 不可读、存在隔离记录或身份不匹配时返回 `important_state_incompatible`，同时标记数据已保留，不允许配对恢复绕过这些重要数据。

Client 当前写入的配置、身份、凭据与队列格式仍为 `0.9.4`；只对已证实结构相同的 0.9.3 账户文档提供只读兼容，不猜测转换采集数据。
