# host-monitor 0.9.31

- 扩展 CPU 型号/厂商/逐核频率、系统负载和网卡 MAC/IP/MTU；Linux 增加链路速率、状态及 hwmon 风扇、电压、电流、功率和能量。
- 新增后台只读 SMART / NVMe 健康采集，支持温度、寿命消耗、介质错误和累计读写量等指标；需要系统安装 smartmontools 并具有设备读取权限。
- Windows x64 新增 AMD ADLX / Intel IGCL 只读遥测，并按 LUID 与 DXGI/PDH 合并。采集温度、功耗、频率、风扇转速和电压；Intel 功耗通过能量差值计算，首次或失效样本保持不可用。
- Linux AMD / Intel 增加 DPM、hwmon、i915 和 Xe 提供的频率读数；Windows 增强逐显卡识别、专用显存和利用率。
- 驱动缺失、接口不支持、版本不匹配和失效读数均保留明确采集状态；后台厂商采集不阻塞常规系统采样。
- 仅监控硬件与系统状态，不枚举进程，不下发远程命令，不进行调频、风扇控制或电压设置。

## 当前版本要求

报告 schema 更新为 **2**，需配套 **Server 0.9.26**。客户端不回退旧协议；旧队列报告保留原始内容隔离，版本拒绝不会清除配对凭据。配置与持久身份格式继续独立使用 `0.9.4`。

Windows 厂商遥测要求与 ADLX **2.0.0.125** / IGCL **1.1** 接口匹配的现代驱动。使用系统驱动 DLL，不附带或自动安装 SDK。详见 [Windows GPU 采集说明](../windows-gpu-vendors.md)。

## 验证与产物

本地 249 项测试通过（1 项外部 OTLP 环境测试忽略），Windows x64 交叉编译、Clippy 和 60 项 SDK ABI 核对通过。实际传感器仍需在 Windows AMD/Intel 目标硬件上验证。标签工作流进一步运行 Linux、Windows、macOS 原生测试、移动库检查和 OTLP 集成测试，再发布 DEB/RPM、MSI、macOS ARM64 PKG 与校验清单。安装包沿用未签名状态。
