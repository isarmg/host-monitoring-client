# Host Monitoring Client 0.9.15

This release removes the product copies of the common CLI/service lifecycle and authenticated local-status channel. The Client now consumes those complete implementations from Client Foundation 0.9.0 and declares only Host-specific options, service identity, paths, telemetry, pairing, and delivery behavior.

Instance authorization codes remain permanent until an administrator replaces or cancels them. A replacement requires explicit re-pairing; network or transaction failures are not described as authorization-code expiry.
