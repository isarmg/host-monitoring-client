# Host Monitoring Client v0.9.6

纯命令行与系统服务改造的预发布版本。macOS 仅支持 Apple Silicon（arm64）；Intel macOS 不再适配、运行 CI 或提供发行附件。

- 移除托盘、Client 本地网页控制和登录自启入口；提供结构化 CLI、配对恢复、只读状态与诊断、配置修订比较、日志和显式服务管理。
- Windows SCM、Linux systemd、macOS launchd 管理长期运行；安装后默认停止，管理员明确启用开机运行。
- 维护与运行互斥，管理员先停服务再修改配置或凭据；保留身份与执行记录，不自动迁移历史格式。
- Windows x64、Linux x64、macOS Apple Silicon 的原生 CI 验证安装与服务生命周期；下载对应平台安装包/归档，并核对 SHA-256 与源码清单。

附件含 Windows MSI、Linux DEB/RPM、macOS Apple Silicon PKG。Host 配置与配对状态格式继续固定为 0.9.4，与程序版本 0.9.6 独立。

安装产物未签名、未公证。本次未完成三平台物理重启后无人登录验收、全部真实网络故障与长时间运行矩阵，也不声明支持历史版本的自动升级或降级。不得删除身份或队列绕过安装与维护检查。

CLI 用法与完整边界见 [改造说明](cli-unreleased.md) 和 [兼容矩阵](cli-compatibility.md)。发布不包含生产部署。

发布回归中的持久状态与配对/OTLP 数据固定为历史格式 0.9.4，程序补丁版本不再影响这些测试输入；不改写用户状态。
