# Host Monitoring Client 0.9.14

This release republishes the latest verified setup and installer behavior under a new immutable version. Reauthorization still uses guarded credential replacement and setup quiesces a running service before pairing. Correction: the 0.9.14 implementation returned a non-success result when initial acknowledgement timed out; it did not continue as a warning. Release 0.9.16 aligns the documented and tested behavior and adds progress output.

Linux, Windows, and macOS packages are rebuilt from the tagged source. The MSI and package hooks install a stopped service and leave interactive setup to an administrator terminal. Protocol and persisted-state formats are unchanged from 0.9.13.
