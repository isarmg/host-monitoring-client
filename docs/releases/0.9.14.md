# Host Monitoring Client 0.9.14

This release republishes the latest verified setup and installer behavior under a new immutable version. Reauthorization still uses guarded credential replacement, setup quiesces a running service before pairing, and an initial acknowledgement timeout remains a warning after successful configuration and service startup.

Linux, Windows, and macOS packages are rebuilt from the tagged source. The MSI and package hooks install a stopped service and leave interactive setup to an administrator terminal. Protocol and persisted-state formats are unchanged from 0.9.13.
