# Host Monitoring Client 0.9.17

Setup now reports redacted, stable DNS, Fake-IP/address-policy, TCP, TLS,
timeout, response-budget and HTTP contract failures instead of collapsing them
into `pairing_server_unavailable`. An explicit `--server` change is processed
before the old endpoint can be contacted and requires identity-recovery
confirmation. Credential probes recheck the locked pairing revision, and all
Setup phases consume one deadline.

Persisted bearer credentials must use the exact current 64-character lowercase
hex encoding. Tagged CI injects and verifies the full source commit in the
native executable so `host-monitor version --format json` cannot report an
unknown release identity.
