# host-monitoring-client 0.9.33

- Windows x64 增强 AMD ADLX 与 Intel IGCL 遥测：补充功耗、温度、频率、风扇和电压采集，改进驱动能力诊断；旧 AMD 驱动缺少 GPU LUID 时保留独立传感器读数，避免重复汇总利用率和显存。
- 增加 Windows 系统热区温度采集；是否有读数取决于固件是否向 Windows 暴露传感器。
- Windows MSI 随包安装经固定 SHA-256 校验的 smartmontools 7.5 `smartctl`、驱动数据库、许可证及对应源码，用于只读 SMART 健康采集。Linux DEB/RPM 增加对系统 `smartmontools` 包的依赖。
- Windows 安装器及 CI 增加对 smartmontools 载荷和安装过程的验证。

Windows AMD/Intel GPU 读数仍取决于具体显卡和驱动；真实硬件上的持续采样需要在目标设备上核对。
