# Host Monitoring Client 0.9.24

- 交互输入改用 Foundation 0.9.10 的原生控制终端实现；macOS/Linux 不再执行 `stty`，Windows 不再启动 PowerShell 读取授权码。
- Server 地址与授权码分别限制为 2048 和 256 字节，并将 `--timeout` 覆盖到输入阶段；超时、取消、缺少终端及终端模式错误有独立错误码。
- 授权码输入前明确提示内容不会显示，秘密字符串在使用后自动清零。
- 普通 `setup` 遇到未完成的配对请求时明确询问是否继续；默认重新输入授权码，`setup --interactive` 始终提交新授权码到同一 pending 请求。
- 保持现有配置、Host UUID、队列和当前服务协议格式，不引入旧输入后端或旧协议兼容路径。
- 同源 Pending 仅在未过期时复用；本地已过期事务会自动生成新的 generation、request ID 和密钥，无需删除状态目录。
- Create、Activate 和 Poll 的 HTTP 错误按操作分类；只有结构化 `unsupported_client_protocol` 才报告协议不兼容，404/405/426 分别报告入口、方法和升级问题。
- Activate/Poll 收到结构化事务不存在响应时，以 generation、request ID、endpoint 和 polling secret 做 CAS 后持久转为 `Expired`，不触碰 identity、credential 或上报队列。
