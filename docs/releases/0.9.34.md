# host-monitoring-client 0.9.34

- Windows 使用系统接口表中的硬件接口标志采集物理网卡；Linux 只收录能关联到 sysfs 设备的网卡，排除虚拟接口。macOS 暂无可确认的物理网卡来源，发送空列表。
- 物理网卡和逻辑接口分别上报。物理网卡包含硬件标识、名称、关联接口、MAC 与可用链路速率；逻辑接口继续提供 IP、MTU、状态和流量计数。
- 报告协议提升至 schema `3`，硬件快照必须包含 `physical_networks` 列表。须配套 Server 0.9.30；旧 schema 报告按既有规则隔离，不自动转换。

Linux 采集测试和 Windows 目标编译检查通过。物理网卡识别结果仍应在目标设备上核对。
