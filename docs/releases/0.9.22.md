# Host Monitoring Client 0.9.22

- 修复已完成配对后系统服务保持 Running、但永久停在等待配对状态且不上报数据的问题。服务启动现在优先加载当前 `Active` 配对的身份、端点和凭据，然后才处理未完成替换期间的旧凭据回退。
- 修复 `host-monitor queue drain` 在正常 `Active` 配对下错误返回 `awaiting_pairing` 的同源状态选择问题。
- 新增服务启动回归测试，要求当前已完成配对必须在一秒内生成 Reporter，防止再次进入 60 秒等待循环。
- 配置、Host UUID、长期凭据和待发送队列格式均未改变；从 0.9.21 升级后不需要重新配对，重启服务即可继续使用现有绑定并补发队列。
