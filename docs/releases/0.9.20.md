# Host Monitoring Client 0.9.20

- 公网配对、激活、遥测和网络诊断改用产品自有的标准 Reqwest 客户端，遵循系统 DNS、代理、VPN 和 TLS 信任。
- 正式端点继续严格要求 HTTPS、同源激活地址、禁用重定向，并保留请求、响应和头部大小限制。
- 删除共享 DNS/Fake-IP/IP 地址策略及同步网络适配；配置、身份、队列和服务协议格式保持不变。
- TLS 客户端身份与额外 CA 配置继续兼容；额外 CA 与系统根证书合并使用。
- HTTPS 测试夹具使用规范化的物理临时目录路径，在 macOS 上继续验证禁止通过符号链接读取 TLS 输入的安全边界。
