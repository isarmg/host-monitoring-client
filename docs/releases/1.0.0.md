# xsoc 1.0.0

[发行页](https://github.com/isarmg/xsoc/releases/tag/v1.0.0)提供 Windows x64 MSI、Linux x86_64 DEB/RPM 和 macOS arm64 未签名 PKG。各平台摘要见 SHA256SUMS-*。

本版只读采集主机指标，经本地有界队列向 xsos 上报；报告 schema 1，配置与账户格式 1.0.0。

## 开始使用

[安装并配对](../platform-setup.md) → [确认运行](../usage.md) → [日常维护](../administration.md)。当前发布资产的源码身份由对应 manifest / version 输出确认，main 的后续提交不自动进入现有包。

## 验证范围

平台原生构建、安装器、服务生命周期、网络协议与传感器测试分别记录。协议夹具和编译通过不等于全部设备实测；在目标主机按安装页完成业务验证。开发命令见[开发指南](../development.md)。
