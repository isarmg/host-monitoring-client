# Host Monitoring Client 0.9.9

修复 Windows MSI 在旧服务登记残留、程序和状态目录已经丢失时于 PrepareClientInstall 步骤报 1722/1603 的问题。安装器验证原服务的固定路径和 LocalService 身份后修复安装，并默认记录受保护的详细失败原因。

新增 Windows 安装修复脚本，处理早期 MSI 产品登记、重试安装器忙碌、强制覆盖损坏或同版本程序文件；后续 MSI 使用稳定升级标识。Linux 与 macOS 接受兼容旧版的账户所有权记录，覆盖安装无需清除凭据和队列。

新增 [各平台安装配置指南](../platform-setup.md)，包含 Windows 管理员终端、DEB/RPM、Apple Silicon PKG、配对、服务操作、配置路径和日志。配置及持久身份格式仍为 0.9.4，程序版本为 0.9.9。

CI 回归覆盖残留服务、旧标记保留、损坏程序强制替换，以及原有 ACL、回滚与卸载行为。发行安装包未签名、未公证；macOS 仅支持 Apple Silicon。

修复 Windows PowerShell 5.1 将 MSI COM 方法空返回值混入属性结果，导致官方安装包被误判的问题。原生 CI 直接运行随包提供的修复脚本，验证损坏程序被替换且设备身份保留。

修复旧版 MSI 已撤销状态目录的服务权限、SCM 服务登记仍短暂存在时，跨版本升级误报缺少服务 SID 的问题。仅接受固定服务路径、已停止服务及精确受保护的卸载保留 ACL，安装后恢复服务权限。新增从公开 0.9.7 MSI 实际升级并保留设备身份的原生回归。
