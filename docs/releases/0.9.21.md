# Host Monitoring Client 0.9.21

- 修复默认交互式 `setup` 在服务端拒绝旧凭据时错误丢失交互输入模式、继而返回 `protected_input_required` 的问题。
- `setup` 现在把 Fresh、Resume、Replace 和 Recover 建模为互斥动作，并由实际动作决定是否需要受保护输入，避免恢复或替换流程沿用 Resume 的输入策略。
- 失效绑定会自动进入交互式身份恢复，保留原 Host UUID 和待发送队列；受保护 stdin 自动化与显式 `pair recover --interactive` 继续兼容。
- 新增动作优先级和输入模式回归测试，并明确 CLI 帮助中的默认交互行为。
