# Host Monitoring Client 0.9.26

- 配对轮询仅在服务端返回专用事务错误且 `request_id` 与本地事务一致时更新本地终止状态；普通 404 不再误判事务失效。
- 支持服务端新的 `410 pairing_transaction_expired` 错误，并保留缺失事务与过期事务的区别。
- 打包示例地址在诊断中明确报告 `awaiting_configuration`，不再触发无意义的网络探测。
- macOS 安装只部署并注册服务，交互式 `setup` 由管理员在安装后显式执行。
- Client Foundation 更新至 `0.9.14`，Windows 提权安装等待现在有明确超时和稳定错误码。

本版本不包含安装包签名或公证，也不新增旧版本状态迁移。
