# Host Monitoring Client 0.9.12

- 修复 Windows MSI 完成后以普通用户运行 Setup、无法访问受保护 ProgramData 状态的问题。交互式 Setup 现在先检查管理员令牌，必要时通过 Windows `runas` 请求 UAC，并等待提升后的进程完成。
- 安装器发起的 Setup 会保留结果窗口；UAC 取消或提权失败会显示明确的配置阶段错误。stdin 自动化不会丢失输入，而是要求调用方从管理员上下文运行。
- 人类可读错误改为最多三行：错误码与失败步骤、压缩后的单行原因、可直接执行的下一步。底层诊断详情限制为 240 个字符，JSON 自动化合同仍保留稳定字段。
- 配置、配对、服务注册、启动策略、服务运行和连接六个后置验证关卡保持不变；机器 PATH 的安装、修复、升级和卸载事务语义保持不变。

Windows x64、Ubuntu 24.04 x64 和 macOS Apple Silicon 原生产物由标签对应提交构建。产物未签名、未公证；安装前核对同页 SHA256SUMS 与 manifest 中的源码提交。
