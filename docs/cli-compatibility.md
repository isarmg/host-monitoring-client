# xsoc 1.0.0 当前兼容边界

客户端支持 Windows x64、Linux x64 与 macOS Apple Silicon。部署时核对安装包版本、源码身份、服务端版本及配置状态。

| 维度 | 当前契约 |
| --- | --- |
| 客户端程序 | 1.0.0 |
| 服务端 | 报告结构 1 |
| 客户端配置与身份 | 只接受当前格式 1.0.0；软件发行号不改变该独立格式 |
| 本地队列 | 保留主机 UUID、报告 ID 和待发送报告的原有归属 |
| CLI 的 JSON 输出 | schema_version 1；--format json 为机器输出入口 |
| xcsc | 1.0.0，固定提交 c45e48e93e360542c2e1db6c6441a9e29b344b03 |
| 主机协议包 | 1.0.0，固定提交 3b5c437a80424c717a20ffbad07c3e8d01cd83ae；结构 1 报告字段 |
| IPC | xcsc GetStatus/1，校验进程世代与绑定 |

安装器负责程序和服务的覆盖或修复，并按平台保留配置、身份与待发送队列；具体步骤见平台安装指南。配置或账户资料不兼容时，客户端返回明确错误；管理员须先验证队列，再通过受支持的配对恢复命令归档不兼容账户文件。未知或损坏的队列不能通过删除状态或重新配对绕过校验。

服务端数据库的备份或恢复流程不适用于客户端状态。客户端不提供跨平台状态复制，也不承诺自动降级。

当前软件基线为 1.0.0，配套安装与诊断步骤见[分平台部署指南](platform-setup.md)。
